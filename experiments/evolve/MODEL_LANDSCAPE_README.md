# Triggle Hugging Face model landscape scan

Read-only, no tokens, no paid inference. It samples up to 250 popular models in each of seven task groups, inspects targeted official cards, and enumerates all chat-compatible Inference Providers returned by the router. It does not claim to have exhaustively tested every Hugging Face repository or benchmarked model quality. Results saved as GitHub Actions artifact on experiment/evolve-shadow-v1-20261122; no site files or main branch touched.

Security: contents:read, no Hugging Face token, no model invocations or dynamic source modifications. Model use requires later targeted external validity and licensing review.
