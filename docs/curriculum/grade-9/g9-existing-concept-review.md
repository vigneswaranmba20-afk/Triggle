## Changes and boundaries

- Set Language keeps seven lessons. Tamil set-builder output, control names, Venn accessibility descriptions and immediate feedback were checked. Related numbered exercises currently exist for the first three lessons. The other four lessons include their own practice and the chapter data has no numbered §1.5–1.8 exercise destination for them.
- Real Numbers keeps eight lessons, including the cumulative review. The rationale now covers exact construction of a root and important surd classifications. Eight exercise links connect the existing concepts to available questions.
- Algebra keeps ten lessons and existing exercise links. Tamil captions, formula lettering, spoken labels and feedback accompany the same interactions. The linear-system rule uses products and differences of coefficients, so a zero coefficient never forces a division by zero.
- Mensuration keeps four lessons. The first now uses its existing triangle diagram to compare the base–height method from §7.1 with the three-side method from §7.2. Tamil diagram units and mathematical captions cover all four concepts.
- Specialist Tamil textbook editorial sign-off remains pending. No exercise wording, answers, videos or progress keys changed in this concept review.
