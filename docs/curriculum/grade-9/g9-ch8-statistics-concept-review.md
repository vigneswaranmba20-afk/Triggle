# Grade 9 Chapter 8 Statistics concept lessons

The six English lessons from PR #308 are recovered on current main and paired with original Tamil teaching, controls, accessible visual labels, display-math descriptions and practice feedback. The chapter keeps the existing 30 numbered records in Exercises 8.1–8.4, their IDs and their saved progress. The currently available exercises open in English. The Tamil lesson links identify that language before a student opens an exercise.

The grouped mean treats each class midpoint as its representative. The lesson uses `uᵢ` for the scaled deviation so it stays distinct from the unscaled deviation `dᵢ`. The textbook reuses `d` in the step-deviation method. The grouped median uses the first class whose cumulative frequency reaches half the total, so an exact boundary gives the upper boundary of that class. The grouped mode demonstration uses equal-width classes with a unique highest frequency and a neighbour on each side. Its example with frequencies 2, 5, 3 estimates 16 minutes and reversing the outer frequencies estimates 14 minutes.
