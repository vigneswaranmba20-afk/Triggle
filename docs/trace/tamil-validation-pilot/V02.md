# V0.2 Tamil grammar experiment

This is an isolated read-only pilot. The public Tamil mT5 model card specifies the prefix `correct this:`, maximum sequence length 128, and four beams. Inference resolves a public immutable Hugging Face revision before fetching only tokenizer/config/safetensors files; no custom model code or tokens. Model dependencies are pinned; no paid inference API is invoked.

The existing 60-case development benchmark is reproduced. Inference receives normalized Tamil input without question numbering; it never reads labels. The separate scorer measures changed-text flags, exact reference restoration, numeric changes, skipped cases and combined recall/precision. An edit is a suggestion, not a grammatical error verdict. Overlength or incomplete cases are unresolved, not silently passed. No student files or production gates are changed. Run timeout: 30 minutes. A failed install/download/inference is a real blocker, not a passing model score.

Source: https://huggingface.co/manavdhamecha77/GEC-mT5-Small-Tamil . No model inference results are claimed before the hosted run completes.
