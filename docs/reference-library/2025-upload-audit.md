## Necessary caveats and review plan

1. **Uploaded files are reference evidence only.** The repository contains **only metadata, SHA-256 fingerprints, printed-page references and selected terminology**, not the copyrighted book PDFs. Codex does not automatically gain access to conversation-local PDFs via a GitHub checkout; an approved accessible file mechanism or a fresh attachment in its working session is needed to read actual questions/figures.
2. **Previous research isn't invalidated.** The historical 2018–2024 sources remain as provenance but should not be mistaken for the latest copy in hand. Prefer the uploaded 2025 PDFs for new 2025-aligned editorial work where accessible.
3. **Not a claim of 2026–27 equivalence.** The original source list and the official distribution listing document different kinds of evidence. They do not certify matching current-year printings.
4. **Full Tamil terminology flags stay `pending`.** Terminology in a contents page is confirmed, but Triggle has not reviewed every formula, instruction, exercise and explanation in all 41 chapters. Mark `verified` only once the actual chapter lessons have had bilingual editorial review.
5. **Exact exercise fidelity isn't yet certified.** Each Phase 2 question should be mapped to Grade / Chapter / Exercise / question number / medium / printed page and mathematically checked against the 2025 PDF (or final prescribed edition).
6. **Page offsets differ by medium.** Example: Grade 10 Chapter 6 starts on **printed page 239 (English)** and **247 (Tamil)**. This is intentional, not an inconsistency.
7. **No site changes in this audit.** The 41 navigation chapters, existing 105 question IDs and publication statuses are unchanged.
