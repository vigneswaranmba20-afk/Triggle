# Similar-triangle compass construction

All five construction steps model the same original PQR triangle. The tool places equally spaced compass marks on the ray QX, joins Qₙ to R, and draws the parallel through Qₘ to find R′. The extensions for m > n remain collinear with the original sides. The last step draws the scaled triangle from the exact same centre and factor. The ray points use subscripts and can move to keep the core vertex labels clear. The bilingual compass key names the full range of points and identifies both active marks.

The retained ratios and steps follow §4.2.3 of the 2025 Tamil Nadu textbook, English PDF pages 175–177 and Tamil PDF pages 179–181. The graphical regression checks each compass interval, the numerator and denominator endpoints, the parallel lines, the exact side ratios, and normal and reverse step navigation.
