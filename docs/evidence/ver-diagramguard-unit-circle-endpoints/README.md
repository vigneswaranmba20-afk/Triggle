# Grade 9 unit-circle endpoints

At 0° and 90°, the point P is exactly (1, 0) or (0, 1) on a radius-one quarter circle with equal axis scales. The selected angle is in a wrapping caption. The plot places O, P, x and y against the rendered geometry using the same measured layout as the coordinate lessons.

The construction follows section 6.2 of the 2025 Grade 9 Tamil Nadu mathematics editions, English PDF pages 234–238 and Tamil PDF pages 248–252. The lesson's ratio values, content and acute-angle triangle figures are preserved.

## Matched browser captures

Chromium mobile emulation at 320 CSS px and independent 200% text enlargement. The old figure clipped the y-axis name in all four captures. The rendered labels were approximately 15.5 CSS px even with text enlargement. The replacement measured 30 CSS px and had zero label-to-stroke, label-to-label or boundary flags in those captures. The permanent browser fixture also checks equality of axis scales, the circle radius, the coordinates of P, the angle and the figure's horizontal fit.
