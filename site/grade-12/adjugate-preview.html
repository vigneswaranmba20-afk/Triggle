Exercise 1.1 · Q1(i)

2025 revised: English Vol. I p.15 (PDF 23); Tamil Vol. I p.16 (PDF 24).

A = [ -3 4 ] [ 6 2 ]
Show worked solution
  1. For a 2×2 matrix [a b; c d], adj(A) = [d −b; −c a].
  2. Substitute a=−3, b=4, c=6, d=2.
  3. Hence adj(A) = [2 −4; −6 −3].
  4. Check: det(A)=(−3)(2)−(4)(6)=−30, and A·adj(A)=[−30 0; 0 −30].
  1. 2×2 அணி [a b; c d] இன் சேர்ப்பு அணி [d −b; −c a] ஆகும்.
  2. a=−3, b=4, c=6, d=2 எனப் பதிலிடுக.
  3. எனவே adj(A) = [2 −4; −6 −3].
  4. சரிபார்ப்பு: |A|=(−3)(2)−(4)(6)=−30; A·adj(A)=[−30 0; 0 −30].

Exercise 1.1 · Q1(ii)

2025 revised: English Vol. I p.15 (PDF 23); Tamil Vol. I p.16 (PDF 24).

A = [ 2 3 1 ] [ 3 4 1 ] [ 3 7 2 ]
Show worked solution
  1. Calculate cofactors using Cᵢⱼ=(−1)ⁱ⁺ʲ times the minor determinant.
  2. First row: C₁₁=8−7=1; C₁₂=−(6−3)=−3; C₁₃=21−12=9.
  3. Second row: C₂₁=−(6−7)=1; C₂₂=4−3=1; C₂₃=−(14−9)=−5.
  4. Third row: C₃₁=3−4=−1; C₃₂=−(2−3)=1; C₃₃=8−9=−1.
  5. Transpose the cofactor matrix: adj(A)=[1 1 −1; −3 1 1; 9 −5 −1].
  6. Check: det(A)=2; both A·adj(A) and adj(A)·A equal 2I₃.
  1. Cᵢⱼ=(−1)ⁱ⁺ʲ × சிற்றணிக்கோவை மதிப்பு என்ற முறையில் இணைக்காரணிகளைக் கணக்கிடுக.
  2. முதல் வரிசை: C₁₁=8−7=1; C₁₂=−(6−3)=−3; C₁₃=21−12=9.
  3. இரண்டாம் வரிசை: C₂₁=−(6−7)=1; C₂₂=4−3=1; C₂₃=−(14−9)=−5.
  4. மூன்றாம் வரிசை: C₃₁=3−4=−1; C₃₂=−(2−3)=1; C₃₃=8−9=−1.
  5. இணைக்காரணி அணியை நிரை-நிரலாக மாற்றுக: adj(A)=[1 1 −1; −3 1 1; 9 −5 −1].
  6. சரிபார்ப்பு: |A|=2; A·adj(A)=adj(A)·A=2I₃.
